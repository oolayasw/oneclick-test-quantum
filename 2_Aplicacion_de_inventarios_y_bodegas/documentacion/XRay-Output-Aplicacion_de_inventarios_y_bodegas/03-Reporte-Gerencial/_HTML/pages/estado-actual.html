Aplicacion de Inventarios y Bodegas — SoftwareOne

Qué hace la aplicación

La Aplicación de Inventarios y Bodegas gestiona el control completo de existencias: productos, categorías, almacenes y todos los movimientos que afectan el stock (entradas, salidas, traslados y ajustes). Soporta 5 dominios funcionales y 25 operaciones de negocio.

Sobre qué opera

Plataforma web ligera construida con Python/Flask, arquitectura monolítica de archivo único (God Module de 939 LOC). Base de datos SQLite embebida. Sin separación de capas ni preparación para la nube.
